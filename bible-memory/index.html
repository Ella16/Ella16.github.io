네비게이토 성경 암송(TMS) 무료 웹앱

네비게이토 성경 암송은 주제별로 성경 구절을 외우는 네비게이토의 검증된 암송 시스템(TMS, Topical Memory System)입니다. 이 무료 웹앱은 개역한글 본문으로 그리스도와의 새 출발·동행, 확립, 무장 과정을 비롯해 5·8·60·100·180·900구절과 DEP 242구절을 주제별로 보고, 참조·제목·구절을 가리고 맞추는 힌트, 장절만 보고 제목·구절을 직접 써서 채점받는 테스트, 진도 추적으로 암송하도록 돕습니다. 설치 없이 휴대폰 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 오프라인에서도 열립니다.
