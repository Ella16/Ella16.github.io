DashMacro가 뭔가요

브라우저에서 하는 일 중에는 "똑같은 클릭을 수백 번 반복하는 것 말고는 방법이 없는 작업"이 있습니다. 사이트가 API를 제공하지 않거나, 제공해도 그 기능만 빠져 있는 경우죠.

DashMacro는 그런 작업을 위한 유저스크립트 매니저입니다. 자바스크립트로 작성한 스크립트를 등록해 두면 지정한 사이트에 접속할 때마다 자동으로 실행됩니다. Chrome의 공식 chrome.userScripts API를 쓰는 Manifest V3 확장 프로그램입니다.

주요 기능

  • 표준 유저스크립트 지원 — ==UserScript== 메타데이터 블록을 그대로 사용 (@name, @match, @include, @exclude, @run-at)
  • 내장 편집기 — 확장 프로그램 안에서 바로 스크립트 작성·수정
  • 사이트별 자동 실행 — @match 패턴으로 원하는 주소에서만 동작
  • 대시보드 — 스크립트별 등록 상태·실행 횟수, 도메인별 역방향 조회
  • 백업/복원 — 전체 스크립트와 설정을 JSON으로 내보내기·가져오기
  • GM_ 함수 호환 — GM_getValue / GM_setValue / GM_addStyle 등
  • URL로 설치·업데이트 — .user.js 주소로 가져오고 @version으로 갱신 확인
  • 로컬 저장 — 모든 스크립트는 브라우저 안에만 저장되며 외부로 전송되지 않습니다

인증 매크로 — 직접 안 짜도 되는 것들

자주 쓰이는 작업은 검증된 스크립트를 확장 프로그램에 기본 포함해 두었습니다. 스크립트를 작성할 줄 몰라도 켜기/끄기만 하면 됩니다.

스마트스토어 자동 그룹

스마트스토어 판매자 센터의 판매중 상품 목록에서 같은 카테고리끼리 자동으로 골라 그룹(묶음) 상품 전환까지 실행합니다. 그룹 상품은 API가 제공되지 않아 손으로 할 수밖에 없는 작업입니다.

설치 방법

현재 크롬 웹스토어 등록을 준비 중입니다. 등록이 완료되면 이 페이지에 설치 링크가 올라갑니다.

공통 — 사용자 스크립트 허용

Chrome 138 이상에서는 보안 정책상 사용자 스크립트 실행이 기본으로 잠겨 있습니다. chrome://extensions → DashMacro 상세 페이지 → 사용자 스크립트 허용 토글을 켜 주세요. 이 토글을 켜지 않으면 스크립트가 등록만 되고 실행되지 않습니다.

자주 묻는 질문

Tampermonkey 같은 도구와 뭐가 다른가요?

DashMacro는 Chrome이 공식 지원하는 chrome.userScripts API 위에서 동작하는 Manifest V3 확장입니다. 스크립트는 페이지의 자바스크립트와 분리된 격리 환경에서 실행되며, 외부 라이브러리(@require)는 지원하지 않습니다.

스크립트를 짤 줄 몰라도 쓸 수 있나요?

네. 위의 인증 매크로는 켜기만 하면 됩니다. 직접 만들고 싶다면 대시보드의 가이드 탭에서 "AI 프롬프트 복사"를 누르면, 작성 규칙이 담긴 프롬프트가 클립보드에 복사됩니다. 그대로 AI에게 붙여넣어 스크립트를 받으면 됩니다.

내 스크립트가 어디로 전송되나요?

아니요. 모든 스크립트와 설정은 브라우저의 로컬 저장소에만 보관되며 서버로 올라가지 않습니다.
